# Ulas Rasa

A Yelp-like web application built as a personal learning project.

## Tech Stack

- **Frontend:** TypeScript + React + Next.js
- **Backend:** Python + FastAPI
- **Database:** PostgreSQL
- **Infrastructure:** Docker + Fly.io + Vercel

## Goals

- Deepen understanding of React and Next.js
- Learn Python and FastAPI from scratch
- Build strong backend and infrastructure fundamentals
