# Ulas Rasa - Project Context

## About
A Yelp inspired application for community base business review.
It focused on:
- Adding business
- Leave a review
- Vote a review

## Goal
This project is aimed to practice complex system design concept by building full application.
Through this, dev will learn topic not covered in dev's day-to-day work or enhance topic from dev's day-to-day work.

### Tech stack
- **frontend**: Typescript, React, Next.js
- **backend**: Python, FastAPI, Psycopg
- **database**: Postgresql
- **Infrasturcture**: Docker, Fly.io, Vercel

## Features
These are the feature that will be delivered:
- User registration
- Business management
- Review and rating

Details will be at each feature's Product Requirement Document(PRD)

## Out of Scope
- Location base business discovery
